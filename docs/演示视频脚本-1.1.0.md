# 《巧裁》1.1.0 演示视频脚本（4分40秒）

## 0:00–0:25 真实问题

画面：校园手工材料、裁坏或难复用的余料。
旁白：说明少量多样制作中“不会建模、不会排料、排完不会裁、余料找不到”的实际问题。不得使用未验证的节约比例。

## 0:25–1:20 智能体理解与工具调用

现场输入一个未写全的制作需求。展示智能体只追问一个必要字段，随后显示结构化任务卡。展开工具证据：可用材料数量、需求校验、候选数量、独立校验器、模型 ID 与算法版本。说明大模型负责理解和调度，确定性算法负责几何结果。

## 1:20–2:10 A4 尺寸授权取舍

先展示 105×70 mm 精确尺寸候选，再由用户明确输入“允许宽度最多缩小 1 mm”，展示 104×70 mm 候选。强调两个候选的零件尺寸不同，变化由用户授权，智能体不能静默修改。点击“确认并正式求解”，现场重新查询库存并进入方案比较。

## 2:10–3:10 KT 板异形流程

展示 C 拍照识别纸样，填写真实宽度；切换 B 点绘校正节点；运行 PROFILE 排料。与相同轮廓、数量、间距的逐行基线对比。展示识别失败时的人工校正边界，不宣称自动测量。

## 3:10–3:55 裁切与余料复用

按裁切步骤操作，拍摄成品测量和余料测量。完成结案后，把实测余料登记回材料库，再用于下一次任务。说明材料只在结案后扣减，重复提交由幂等键拦截。

## 3:55–4:25 实测与三人体验

展示 A4、KT 两组记录表原始数据以及三名体验者的完成时间、求助次数和原始意见。只陈述观察，不作统计推广结论。失败或超差项目必须显示。

## 4:25–4:40 原创范围与能力边界

展示源码结构：团队原创的智能体编排、几何算法、独立校验、A/B/C 录入、确认和余料闭环；第三方依赖与 AI 辅助代码清单。画面显示实际模型 ID。结尾说明：本系统面向二维单层材料，图片识别仍需用户给定比例和人工校正。

## 导出检查

- MP4，H.264 + AAC，1080p。
- 时长不超过 5 分钟，文件不超过 150 MB。
- 建议总平均码率约 2.5 Mbps；导出后以实测文件为准。
- 所有画面使用同一 1.1.0 版本；模拟模式必须显著标记，不能作为真实模型证据。
