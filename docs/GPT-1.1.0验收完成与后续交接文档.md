## 1. 当前项目与架构稳态

《巧裁》是一个面向校园手工与模型制作的微信小程序。它包含一个基于 0.1mm 整数精度标度的几何排料求解器（处理矩形 Guillotine 和多边形 PROFILE 排料），以及一个接入了大模型的“AI 制作智能体”。

### AI 智能体运行机制 (1.1.0)
- **大模型接入**：目前已通过云函数直连 **DeepSeek 官方 API (`deepseek-flash`)**，绕过了腾讯云 CloudBase 个人版无法调用大模型的限制。密钥已安全配置为云环境的环境变量。
- **四个只读核心工具**：
  1. `list_available_stocks`（查询可用材料）
  2. `validate_requirement`（校验尺寸限制及权限）
  3. `solve_and_compare`（调用排料算法并进行严格重叠/越界校验）
  4. `build_cut_summary`（生成裁切步骤与摘要）
- **人在回路 (Human-in-the-loop)**：大模型只负责理解意图、追问条件和调用只读工具，**没有写入执行记录或消耗真实材料的权限**。最终结果必定需要用户在界面上核对排料图并点击确认，随后由确定性代码走事务机制消耗材料。

## 2. 之前解决的重大历史阻塞

在 1.1.0 的开发末期，我们曾遇到 `validationPassed=false` 导致无法出图的严重 Bug，现已彻底修复。了解这些有助于你避免修改代码时重新踩坑：
- **材料单位误用问题**：之前线上的演示 A4 材料以毫米 `210×297` 保存，而排料求解器需要的是 0.1mm 整数 `2100×2970`，导致材料远小于零件而求解失败。已在 `cloudfunctions/api/index.js` 的 `prepareDemo` 中加入修复逻辑，自动删除并纠正了单位。
- **JSON 稳定性与状态控制**：大模型的 System Prompt 已被深度调优，确保只输出纯 JSON，且只有在四个工具按序调用完成、并且服务端几何校验出有效排料候选后，才允许输出 `AWAITING_CONFIRMATION` 状态。
